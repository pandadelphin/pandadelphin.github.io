SKATERBOY / Controls

Touch / smartphone
LS / RS circles: front / rear foot; drag from the center.
LT / RT thumb zones: slide left on LT, right on RT for more pressure, release to let go. Enable optional tilt steering in Settings. Use both thumbs together to pump, or hold either PUMP above the triggers with one thumb.
B above LT: brake. A above RT: push. LB / RB: catch. Down / Up: set / return to marker.
Ollie: keep RS held down and flick LS up. Add a sideways LS flick for kickflips / heelflips. Reverse feet for a nollie.
Drag the uncovered park to orbit; pinch to zoom. Landscape gives more room.

Gamepad (standard Xbox / PlayStation)
A / Cross or X / Square: push. B / Circle: brake.
LT / L2 and RT / R2: steer; in air: body spin.
Both triggers: pump on transitions.
Keep right stick DOWN, flick left stick UP: ollie.
Flick front foot sideways at pop: kickflip / heelflip.
Scoop rear foot sideways: shuvit; combine both sticks.
Reverse feet for nollies. Bumpers: catch (auto-catch also enabled).
D-pad DOWN: set marker. UP: return.

Keyboard
W push / S brake / A,D steer or spin.
Hold Space, release: ollie. Hold Q/E at release: flip.
Hold Z/C at release: shuvit. Ctrl: bigger scoop.
Shift: pump. G: catch. M: set marker. R: return.
I,J,K,L = front foot; arrow keys = rear foot.
Mouse drag: orbit. Wheel: zoom.

Land flat and aligned to roll away. Ollie onto a ledge edge or rail aligned for a grind, sideways for a slide. Hold a foot up/down for nose/tail contacts. Ollie out and link tricks before landing. Open Map & lines for the pump circuit, stair plaza and mega ramp.
